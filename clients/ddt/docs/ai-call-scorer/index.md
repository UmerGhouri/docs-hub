# AI Call Scorer

Scores intake consult calls with AI against a written rubric, so managers can coach and reps can see their own results. The data model, call matching, scoring engine and automation are live, and the follow-on tickets made the scores accurate and reportable. The project is still in progress; this section covers its completed tickets.
