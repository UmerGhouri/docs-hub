# Red Flag Panel

Hired matters show a Red Flags section built from three long formula fields. This project replaced them with one reportable formula field, an admin-managed rule catalog in custom metadata and a Lightning panel with inline fix buttons. It also fixed three broken checks, and the share of flagged matters fell from 58% to 28%.
