# CloudFiles Replacement: DDT-owned Google Drive integration

Replaced the CloudFiles managed package, a paid contract that was not renewed, with a Google Drive integration the firm owns. The new panel shows each record's Drive folder on Matter, Opportunity and Person Account pages, and the firm's own code now creates case folders when a case is hired. CloudFiles could then be switched off and uninstalled.
