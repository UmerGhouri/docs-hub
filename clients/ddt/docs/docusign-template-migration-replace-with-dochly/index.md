# DocuSign Template Migration (replace with Dochly)

The firm's own DocuSign integration still sent every PI contract, and a completed signature is what converts a PI lead into a hired matter. This project moved that contract send to Dochly without breaking the conversion, tidied the related templates and messages, and uninstalled the unused DocuSign managed package.
